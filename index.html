01 / about

composer.json

I'm Mar Carlo — a fullstack developer who thinks in requests and responses as much as in components and classes. My backend of choice is PHP with Laravel: migrations, Eloquent relationships, queued jobs, and clean route files that read like a map of the product.

On the frontend I keep it lean — plain HTML & CSS where it's enough, Tailwind CSS when a project needs to move fast without a design system slowing it down, and JavaScript to make the interface behave. I like shipping features end to end: schema, endpoint, and the pixel that triggers it.
